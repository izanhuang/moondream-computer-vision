# 🧠 Moondream Computer Vision App

This is a simple and interactive web app built with **Streamlit** and powered by the **Moondream API**. It lets users upload images and:

- ❓ Ask a question about the image  
- 🔍 Detect specific objects  
- 📝 Generate a caption for the image

## 📸 Features

- Upload images from your local device  
- AI-powered question answering, captioning, and object detection  
- Clean and responsive interface using Streamlit  
- Powered by the Moondream model

## 🧪 Installation
### 1. Clone the repository
```
git clone https://github.com/your-username/moondream-computer-vision.git
cd moondream-computer-vision
```

### 2. Install dependencies
```
pip install -r requirements.txt
```

### 3. Add Moondream API Key
Create your Moondream API Key from their website.

Create a `.streamlit` folder with a `secrets.toml` file and add your api key.
```
moondream_api_key="<your_api_key>"
```

### 4. Run Locally
```
streamlit run app.py
```
